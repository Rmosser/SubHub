# 玻璃工作台 · 定稿

2026-11-11 定稿：新 UI 按「新沙洲」来。

- **定稿文件**：`final.html`，是 `flow-island.html` 定稿时的拷贝。之后的探索不要改这份。探索稿和变体存档没有入库。
- **清透（浅色）**：沙洲用着色器里的 `river()` 来画，导航底下是发丝耙痕。挤密的线自己亮成岸线，洲形是水滴形，背水面是浅滩。默认变体是 `a`，想要更显时用 `?v=c`。
- **烟熏（深色）**：沙洲走 2D 绘制，默认变体是 `c`。
- **对照开关**：
  - `?river=2d`：清透改回旧的 2D 画法；
  - `?flow=0`：改回透镜版；
  - `?v=a|b|c|d|e`：切换变体；
  - `?seed=N`：固定随机。
- **设计原则「形由流成」**：选中态不画在 UI 上，由介质的变化勾勒出形状，上层 UI 和下层数据流因此有交互。材质按时态分：
  - 恒定的结构，刻在玻璃上；
  - 此刻的状态，是光；
  - 等人处理的事，是纸。产品实现里改成了玻璃片，以 `DESIGN.md`「材质按时态分」为准。

另外：「呵气」已经抽成独立模块，准备给其他项目用，不属于本定稿。
