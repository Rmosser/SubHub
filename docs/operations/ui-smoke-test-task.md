# SubHub 管理端 UI 冒烟测试任务

适用场景：对懒猫微服上的 `/manage` 管理端做一轮无副作用 UI 冒烟测试。

## 测试边界

- 目标是 Web 管理端，不是桌面客户端
- 覆盖主要页面、Tab、表格行内操作、详情抽屉、modal、选择器、复制按钮
- 会写线上状态或触发后端任务的操作，停在最终提交前
- 验证记录只写入 PR 描述或测试报告，不写入生产数据
- 结果必须区分：
  - 正常可用
  - Web 环境预期限制
  - 明显异常 / 疑似 bug
- 冒烟范围以当前可达管理端页面和导航为准；未被路由或组件引用的历史源码不属于用户界面验证面。

## 执行环境

- 使用运行中的懒猫微服实例，而不是本地开发页
- 确认页面 URL 位于目标微服域名下，且路径是 `/manage/...`
- 测试前确认页面标题、左侧导航和模块名称属于当前 SubHub 管理端

## 必测页面

1. `/manage/catalog`
2. `/manage/contracts`
3. `/manage/profile`
4. `/manage/llm`
5. `/manage/pools`
6. `/manage/sources`
7. `/manage/devices`
8. `/manage/review`
9. `/manage/advanced`

九个页面与其中的抽屉、对话框都不出现 `Invalid API response: <字段路径> must be …`。这是前端对响应的运行时校验：字段缺失或类型不符直接报错、不补默认值；出现即按明显异常记录并附上字段路径。

## 响应布局与键盘

- 在390 / 768 / 1440 **CSS px** 验证九个工作区。用 DOM `innerWidth` 核实实际宽度，避免浏览器缩放导致截图尺寸误判。
- 宽屏是左侧刻在玻璃上的导航；`<=900px` 时品牌/外观设置、场景选择、横向滚动的导航依次排在正文上方，换页后当前项自动滚入可见范围，不出现整页横向滚动。
- 点击导航后 `aria-current` 移动，玻璃下的沙洲随之迁移；悬停只改变文字亮度。沙洲岸线是白光带一圈色散，里侧透出一圈很淡的深海青蓝，浅底上也分得清；窄屏随页面滚动或滚到头回弹时，洲落在字后面一点、后侧的岸微微鼓出，停下后约 0.4 秒平顺复原，不回弹、不抖。
- 外观切换（自动 / 清透 / 烟熏）立即生效并在刷新后保留；自动跟随系统深浅色。清透无 WebGL 时退回磨砂，界面仍完整可用，控制台无报错。
- 页面 scrollWidth 不超过 viewport；来源、设备 URL 和表单不撑宽全页，密集表格可在组件内部水平滚动。触屏（`pointer: coarse`）下 Contracts 表头没有列宽调整柄，鼠标下仍有。
- 使用 Tab / Enter / Escape 操作导航、菜单、复制、modal 和详情抽屉（焦点在抽屉内按 Escape 关闭，焦点回到打开它的按钮；抽屉里展开的下拉先收起，第二次 Escape 才关抽屉）。复制成功后焦点仍留在复制按钮，反馈有可见文案与live status。
- 检查中英文的 modal close、详情抽屉的关闭与调整大小（方向键可调，`aria-valuenow` 等于面板实际宽或高）、行编辑/删除的可访问名称；抽屉打开时触发按钮的 `aria-controls` 指向抽屉。服务目录与分类预览的分页按钮读作「上一页 / 下一页 / 第 N 页」；开关与文件选择的读屏名称是字段名，Issues 面板不报 `<label for>` 用法错误。
- 系统启用 reduced motion 后，页面与控件仍能完成相同操作，不出现位移展示动画；玻璃背景静止，沙洲直接成形，空闲时不再请求动画帧。页面切到后台时背景渲染暂停。

## 玻璃一致性

- 除 Profile 外的八个工作区：页标题与左侧导航同名；每页或每个独立区块最多一个实心主按钮（墨色，烟熏里是浅墨底深字，不是钴蓝），条目里重复的动作是普通按钮、图标按钮或行内链接，图标按钮的可访问名称包含对象名。
- 状态只用一个小点加短语（正常青点、要人处理的琥珀或红、停用与等待是空心点），不出现图标和实心彩色徽章；警告不是蓝色。同一个状态不在同一屏说两遍。
- 字体：拉丁与数字是随包的 Geist / Geist Mono（Network 面板里来自 `/manage/assets/`，不走 CDN），中文是系统苹方 / 雅黑；中文标题与导航组标签没有字距。
- 分类与属性是细描边的中性标签；只有代理 / 直连 / 拦截、新增 / 删除 / 变更带一个淡色点；「当前 / 推荐 / 默认」是亮色描边。
- 需要处理的事浮成一片玻璃，片上的字是平的墨；玻璃片与 Cloudscape 容器同为 16px 圆角，片里的纸条更小一档：Sources 里要处理的来源行本身就是那一片，排在最前，原因在片的第二行；GoRelay 的出站代理问题只在 GoRelay 标签页顶部一片；Devices 的 Overlay 问题只在页面顶部一片；Review 未就绪只有一片。片里的 ⋯ 菜单与下拉展开时不被下一片盖住。不出现黄 / 蓝 / 红教学大提示框。
- 失败原因默认最多两行：长原因出现「展开」，展开后变「收起」，键盘可操作；短原因不出现展开按钮。
- 对话框：打开后焦点在对话框内，Esc 和关闭按钮都能关闭，标题是对话框的可访问名称；标题、正文和动作在同一层底，没有更白的页脚；只有一个主按钮，取消是链接按钮；分组管理、固定管理是只读列表加行内编辑，只有「关闭」一个主按钮，没有取消。浅色与烟熏下各开一次。
- 面板不嵌套：面板里的表格没有第二层白底，对话框与详情抽屉里的表格是内嵌样式。Toast 是玻璃底，只有图标带状态色。

## 必测交互

### 复制能力

- 设备 token 复制
- 设备订阅链接复制
- LLM 导出 JSON 复制（只复制导出结果）
- 复制成功后的图标或文案反馈
- 失败时是否有可见提示

### 详情抽屉

- 宽屏（≥1200px）在内容右侧、内容让位不被盖住；窄屏贴在底部，背后的内容被磨砂模糊、不透字
- 390 / 触屏下关闭按钮与贴底分隔条的点击区至少 44×44，图标与握把位置不变
- 表格行点击后是否稳定展开
- 关闭后是否可再次打开
- 切换不同记录时是否串页或残留

### Modal / Confirm / EditableTable

- 打开与关闭
- 关着的对话框不渲染正文（DOM 里只有 Cloudscape 的空根节点）：关闭后再打开，表单和选择照常出现、焦点落在对话框内；服务目录切入切出没有可感知的停顿（隐藏的批量分配不再每次进页都建一整张表）
- 字段聚焦、切换、输入、取消
- Confirm 弹窗是否可安全取消
- EditableTable 的 add / edit / remove 是否至少能走到 UI 层

### 选择器与复杂表单

- 玻璃标签页（Sources、高级设置、LLM 工作流、分类与设备预览抽屉、GoRelay 账号详情）：点击与左右方向键 / Home / End 切换，选中项亮起，切走再切回面板内容正确
- Select / Multiselect
- Toggle
- 文本、数字、Textarea
- 非法 JSON / 文本输入时是否出现异常
- 同一页面打开表单或详情后切换场景：旧弹窗和详情立即关闭，切回原场景也不能恢复旧副本；每次保存只写入打开该工作区时的场景。

### 只观察不提交的高风险按钮

- Refresh Catalog
- Pull Standard Source
- Refresh all GoRelay
- Crawl GoRelay account
- Save / Create / Delete
- Run Review / Clear Cache
- Generate / Preview / Apply LLM workflow
- Activate Snapshot / Disable Subscription
- Import Domain Bindings / Multipliers
- Accept / Dismiss Directness Review

检查点：

- 可见性是否正确
- disabled / loading 状态是否合理
- 点击后是否出现预期确认或输入 UI
- 除非确认无副作用，否则不要执行最终提交

## 每页通用动作

- 顶部按钮 hover / click
- 表格行点击
- Tab 切换
- Select / Multiselect 展开
- Toggle 切换后取消或切回
- Modal 打开后关闭
- 详情抽屉打开后关闭
- 复制按钮点击
- 空态、加载态、错误态渲染
- 部署后仍开着旧页面时进入未加载过的工作区，分包加载失败的错误页点「重试」会整页重载并进入新版本，而不是原样再报错

## 页面重点

### `catalog`

- 分类详情 panel，分类名称按钮可通过键盘打开
- 次级管理操作位于明确标注的菜单，空态说明刷新导入或手动创建的路径
- preview / custom rules 区块
- Create Manual / Bulk Assign 的打开与取消；Manage Groups / Manage Pins 的打开与关闭（Esc 或「关闭」）
- 从其他页悬停或聚焦导航里的「服务目录」后再进入：表格直接出现，不先闪加载态

### `contracts`

- 合同编辑弹窗
- 下拉、输入框、取消关闭
- 检查 `proxy` / `direct` / `reject` 动作切换；`direct` / `reject` 时节点池字段隐藏
- 打开删除确认框后等待引用查询完成；确认按钮在查询完成前保持 disabled
- 有引用或默认去向时显示引用数量、默认影响和已启用替代契约选择器
- 选择替代契约后执行删除；失败时错误显示在当前弹窗内，草稿和选择仍保留
- 无引用且 `can_delete=true` 的契约可直接删除；删除后刷新页面确认契约不会重新出现
- 非默认场景下继承的全局契约仍允许编辑可覆写字段，不能误显示为可删除的 owner 操作

### `sources` 中的目标路由契约

- 新建标准订阅源时目标契约默认为空，未选择可用契约时保存按钮保持 disabled
- 目标列表只显示后端标记为 `can_bind_standard_source=true` 的已启用代理契约
- 直连、拦截、无单一主池或已禁用契约不得出现在可选列表中
- 编辑已有源时若原目标已失效或不再属于当前 owner 作用域，保留为 disabled 选项并要求重新选择

### `profile`

- 只读配置读图，没有输入框：顶栏是客户端分段（Surge / Shadowrocket / Clash Mi）、设备与提示计数；左侧是手机设置页的横向叠放，右侧是按段折叠的原文。
- 点手机行：该行变暖亮、其余行失焦，原文打开对应段、在该行下方插入解释，连线指向该行；点原文可映射的行：手机走到对应页并选中。点露出的上一层返回；手机走进某段的落点页时原文自动打开该段。
- 列表行进入详情页后，详情各行显示该条目的真实值；带 `s` / `r` / `i` 的链接刷新后回到同一位置与选中项，链接中不含订阅 token。
- 密钥在原文中默认打码、逐个点开；手机行始终打码。纸角只出现在 SubHub 功能依赖、需在手机上设置的前提项及其上级导航行，常驻且不可关闭。
- 宽屏下原文栏与手机栈等高，页面不出现整体纵向或横向滚动；`<760px` 手机在上、原文在下。
- 从全局场景菜单「管理场景」进入时，读图下方出现 Scenarios 区域并滚入可见范围；create / edit / disable / delete 流程与确认弹窗可用。
- 从全局场景菜单「创建场景」进入并完成/取消弹窗后，再切换场景或切回原场景，不得重新消费旧导航请求或自动重开创建弹窗。

### `sources`

- 页标题右侧是唯一的「添加来源」主按钮（远程源 / 手动节点），在 GoRelay 标签页点它会切回标准源并打开新建对话框；切走再切回不会重开对话框。
- 标签页：标准源 / GoRelay 带计数，需要处理时多一个琥珀点，读屏读作「…，N 项需处理」；左右方向键与 Home / End 切换。
- Standard Tab：列标题右侧是「N 个需处理」或「全部正常」。正常的行刻在玻璃上，状态是「正常 · N 分钟前拉取」（完整时间在 title），操作是 ghost「拉取」和 ⋯（编辑来源、删除）；⋯ 菜单方向键可走、Esc 回到触发键，删除是红字。拉取失败、告警或兼容性待处理的行排在最前并浮成玻璃片：仍沿用旧节点是琥珀「拉取失败 · 沿用 N 个月前的节点」，没有可用节点是红色并且节点数 0 也是红字；第二行逐个客户端列出状态与主机（等宽、单行省略），状态里的「超时」「请求失败」「未配置订阅链接」随界面语言切换，HTTP 码和解析原因原样显示；手动节点、刷新出错及升级前保存的失败占满一行，没有客户端列；右侧「编辑来源」，按钮是「重新拉取」。拉取中按钮转圈、状态换成「拉取中」，行不挪位。
- 窄屏（≤650px）：节点数到名称右侧（「88 节点」），正常行只剩 ⋯（菜单里多一项「拉取」），片上的「重新拉取」与 ⋯ 在片底，触控目标不小于 44px。
- Standard Tab：Add / Edit modal 的字段与取消；route-contract target 必须由操作者显式选择，空值应保持可见并被校验拒绝，不得静默变为 `medium`
- 首屏只有一组添加远程源/自建节点入口，空态使用简短流程；保存或拉取的结果落在来源行上（原因、「编辑来源」、「重新拉取」）。刷新策略默认折叠，折叠行右侧是「自动拉取 · 每 N 分钟」或「不自动拉取」，展开后四个字段在一片玻璃上，宽屏四列、窄屏一列。
- 标准源名称、远程源两个必填 URL、手动源节点文本与目标契约为空时，表单直接显示必填错误；编辑已有 `direct_only` 源并选择 Default 后，保存应明确恢复 `direct_then_proxy`。
- 标准源保存成功但 `pull_result.ok=false` 时显示“已保存，但拉取失败”警告；源列表请求失败时显示错误及重试，不能显示空源列表；环境状态请求失败时 GoRelay 标签页顶部显示错误及重试，不能显示环境健康。
- GoRelay Tab：账号是刻字行（账号 · 最近结果 · 节点），列标题右侧是「N 个需处理」或「全部正常」；点名称切换下方详情，当前账号名亮着。抓取失败但仍有节点是琥珀「抓取失败 · 沿用缓存的节点」，没有节点是红；ghost「立即抓取」转圈时状态换成「抓取中」，详情标题旁不再重复「立即抓取」；⋯ 里是编辑、删除（≤650px 时多一项「立即抓取」，名称点击区不小于 44px）。GoRelay 标签的琥珀点把失败账号与出站代理问题一起计数。
- GoRelay Tab：详情标签页切换、prompt 型编辑入口的打开与取消
- GoRelay Tab：默认导入链接保持走默认订阅路径，不应因为存在更靠前排序的非默认 scenario 而 silently 切到 `/{scenario_slug}/...`

### `devices`

- 设备交付卡中的client选择、可复制链接和preview为直接可见主区，URL省略不撑宽页面；切换client后preview使用该客户端
- links panel
- preview panel
- 目标类型 / 风格切换
- diagnostics / summary / content 切换
- links panel 不再展示 `LazyCat` / `Raw` profile-flavor 二选一，也不再展开其他 scenario 的链接矩阵
- preview panel 在切换 scenario 时只预览当前选定 scenario 的单一路径，不保留旧的 profile/flavor 参数
- 预览请求失败时状态显示失败，Summary / Content / Diagnostics 均提供重试；同场景订阅状态变化后详情里的复制链接也应读取最新设备列表。
- 已生成但存在错误/告警时状态显示“已生成，存在诊断”警告；Diagnostics 必须展示通用诊断条目，不能只有空的 Blockers / Skipped；级别列按语言显示（错误 / 告警 / 提示 / 致命），未知值原样显示。

### `review`

- primary / target profile 选择器
- 设置里的 Gemini key 状态与服务端 `gemini_api_key_set` 一致；模型或 key 未配齐时只有一片未就绪，配齐后才能运行。

### `advanced`

- Custom Rules / Process Rules / External Proxy Programs 切换
- 表格编辑器、add row、remove row、toggle、select 的前端行为
- Process Rules 匹配类型与服务端一致：`PROCESS-NAME` / `PROCESS-NAME-REGEX` / `PROCESS-PATH` / `PROCESS-PATH-REGEX`；既有记录正确显示，不提供不受支持的 Bundle ID。
- External Proxy Programs 可逐行编辑启动参数，保留参数内空格；端口必须是 `1..65535` 的整数，缺路径/契约或非整数排序在提交前显示错误。
- 编辑表保存期间草稿保留且输入禁用；让请求失败后草稿和保存按钮保持可重试，成功后显示规范化服务器记录。
- System Status 使用 `/api/status` 的扁平 runtime/source/egress 契约，并同时读取 `/api/pools` 与 `/api/devices`
- System Status 的 pools/devices 请求失败时显示错误与重试，不以空数据静默代替；设备列表中的 Overlay 快照必须对应当前选定 scenario
- Policy Backup 的状态请求失败时显示错误与重试；编辑恢复 ref 会清除旧预览，重新预览/同步/应用期间禁改 ref，应用确认只能提交已预览 ref 及 `snapshot_digest`。服务端报快照已变更时清除预览并要求重新预览。

### 初始化入口

- `/manage` 先读取 `/api/setup/status`，未初始化时引导 `/setup`；失败时显示重试，不提前挂载依赖已初始化状态的业务工作区。

## 结果格式

每条记录至少包含：

- 页面 / 模块
- 控件名称
- 操作步骤

## 代理客户端维护的回归入口

- Profile 读图版式：Surge 首页三个分段是功能卡片（彩色标题与图标、开关在标题栏、说明、右下胶囊按钮）；Clash Mi 首页是连接卡（状态点、开关、三段选择、我的配置）与设置卡（行首图标）；Shadowrocket 首页与配置 tab 行首有图标，节点行是圆形国旗。画成行的都能点，点了有解读和连线；「启动」、Tab 栏、工具条只画不响应、没有悬停态。推入、返回、切换客户端时手机栈与原文都不位移。
- 场景菜单「管理场景 / 创建场景」：跳到配置与场景页后场景区滚入视口（读图加载完成后仍对齐）；用户一滚动就不再跟随。
